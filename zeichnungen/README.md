# Zeichnungen / Drawings

**Gültig ist nur die Basis V1.8.1.** Bei den älteren Basen (V1.7, V1.8) blieben einzelne Lamellen nach einem festen Griff hängen. V1.8.1 hat mehr Luft um die Lamellen und behebt das. Ältere Basen bitte nicht mehr drucken.

**Only base V1.8.1 is valid.** With the earlier bases (V1.7, V1.8) individual lamellae could get stuck after a firm grip. V1.8.1 has more clearance around the lamellae and fixes this. Please do not print older bases.
